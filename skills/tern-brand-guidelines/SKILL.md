# Tern Capital — Master Brand Guidelines

This is the authoritative reference for all Tern Capital brand decisions. Follow these rules precisely for every output produced for or on behalf of Tern Capital.

**For PowerPoint slide decks:** also read `/mnt/skills/organization/tern-slide-formatting/SKILL.md` — it has full slide layout and element rules.

---

## 1. Brand identity

Tern Capital is a hands-on software investor focused on founder-led businesses across the U.K. and Europe. The brand reflects three values:

| Value | Expression |
|-------|-----------|
| Precision | Deliberate, considered decisions — in investments and design alike. |
| Directness | Clear communication without noise or ambiguity. |
| Partnership | Warm, human, collaborative — never corporate-cold. |

Every visual decision must communicate clarity and conviction. No unnecessary decoration.

## 2. Logo / wordmark

### Core rules

- **"Tern"** — DM Sans Semi-bold (600), Tern Orange (#eb5c32).
- **"Capital"** — DM Sans Light (300), Near-black (#1a1a18) on light backgrounds, White (#ffffff) on dark/orange backgrounds.
- **No space** between "Tern" and "Capital" — the wordmark is a single unbroken unit.
- Never split the wordmark across two lines.
- The weight contrast between the two halves is the visual identity.
- The grey chevron icon (a 2×2 grid of triangles, alternating light/dark grey) sits immediately to the upper-right of "Capital".

### Approved background variants

| Variant | Background | "Capital" colour |
|---------|-----------|-----------------|
| Primary | White (#ffffff) | Near-black (#1a1a18) |
| Off-white / document | #f7f4f0 | Near-black (#1a1a18) |
| Reversed — dark | Near-black (#1a1a18) | White (#ffffff) |
| Reversed — charcoal | #4a4a48 | White (#ffffff) |

### Clear space & minimum size

- Clear space: cap-height of "T" on all four sides.
- Minimum print width: 35mm.
- Minimum digital width: 120px.
- Always maintain a clean white, off-white, dark, or grey backing panel. Never place the wordmark over a busy background.

## 4. Typography

### The typeface: DM Sans

DM Sans is the only typeface across all Tern Capital materials. It shares geometric precision with the legacy DIN, is available on Google Fonts and Google Slides, and covers weights 300–700.

Available weights: 300 (Light), 400 (Regular), 500 (Medium), 600 (Semi-bold), 700 (Bold).

### Font by context

| Context | Font | Size |
|---------|------|------|
| Google Slides — all text | DM Sans | See slide-formatting skill |
| Google Sheets — all text | DM Sans | 10–12pt |
| Excel — all text | Calibri | 10–12pt (DM Sans unavailable in Excel by default) |
| Charts pasted from Sheets → Slides | Roboto | As per sheet (Google Sheets technical constraint) |
| Print / Word / email | DM Sans or Calibri | DM Sans where available; Calibri as fallback |

### Type scale

| Style | Weight | Size | Tracking | Usage |
|-------|--------|------|----------|-------|
| Display | 700 | 64px | −3% | Hero headlines only |
| Heading 1 | 600 | 48px | −2.5% | Section titles, slide headers |
| Heading 2 | 500 | 32px | −1.5% | Sub-sections, report chapters |
| Heading 3 | 500 | 22px | −1% | Card titles, table headers |
| Body | 400 | 16px | — | All body copy; line-height 1.7 |
| Small / caption | 400 | 13px | — | Footnotes, captions, metadata; Dark Grey |
| Label / eyebrow | 600 | 11px | +10%, uppercase | Section labels, category tags |
| Data / numbers | 700 | 20px+ | −1% | Financial figures, KPIs |

### Typography rules

- Sentence case throughout — not Title Case.
- No bold in body text. Bold is for headers only.
- Avoid underline unless drawing attention to something critical.
- Line spacing: Single (never Multiple/Exact) everywhere. For slide bullets specifically: 1pt space before AND 1pt space after every bullet paragraph (verified from source file — see tern-slide-formatting section 7). For letterhead/document body copy, paragraph spacing after remains 6-12pt as below.
- Avoid hanging lines with only one or two words.

## 7. Spreadsheet standards

### Absolute must

| Rule | Detail |
|------|--------|
| Cell alignment | All cells top-centred; number/date columns right-aligned; text columns left-aligned. |
| Font — Google Sheets | DM Sans, 10–12pt |
| Font — Excel | Calibri, 10–12pt |
| Date format | DD-MMM-YY or DD-MMM only — never DD/MM/YY or DD-MMMM-YY |
| Actuals / Forecasts | Suffix year with A or F: FY24A, FY25F |
| Number suffixes | Always capitalised: £10K, £5M, £2B — never £10k, £5m, £2b |
| Units in tables | Show as £M. If scale changes within a table, note clearly in column header. |
| K/M consistency | Use the same unit throughout. If you write 185K charities, write 37K not 37,000. |
| Named Ranges | All tables must be linked to Named Ranges on Google Sheets — not raw cell references. |
| Distribute rows evenly | Select all rows and distribute height evenly. Starting padding per cell: 0.1. |
| Freeze rows/columns | Where it makes sense — single data sets, multi-year P&L. |
| Charts tab | Use a separate "CH" tab for charts so KM tabs can be collapsed by analysis. |

### Table formatting rules

| Rule | Detail |
|------|--------|
| Borders | Horizontal light grey lines only — no outer borders. Exception: key metrics tables keep all borders. |
| Last row | No bottom border on the last row. Key metrics tables are the exception. |
| Orange box titles | Text in orange boxes must be white. |
| Column headers | As short as possible. Avoids word-wrap where possible. |
| Spacing | Border-to-bullet and bullet-to-text as tight as possible. Starting point: 0.1 padding per cell. |
| Bullets in cells | Left-aligned, close to left border. Use Shift+Enter for new bullet. No trailing space. |
| Sources | Split by semicolons — not commas. Example: Source: Tern Forecasts; Companies House. |
| "Preliminary" label | Only on slides where data is not clearcut. Not on standard data slides. |
| "na" | Use lowercase "na" for not applicable — never "N/A" or "Not Applicable". |

### Sheet tab naming convention

**Pre-LOI:** L (Legend), A (Assumptions), S (Summary analysis), KM (Key Metrics), CH (Charts), PL (P&L), BS (Balance Sheet), CF (Cash Flow), T (Tax), CB (Compensation & benefits), PP (Sales Pipeline), R (Revenue).

**Post-LOI:** CN (Contracts), CO (Corporate), AR (Accounts Receivable), AP (Accounts Payable), DI (Deferred Income), DL (Debt Like items), OL (Other Liabilities), IC (Intercompany reconciliation), OBS (Other Balance Sheet items), QA (Questions & Answers).

### Data table rules

| Rule | Detail |
|------|--------|
| Numbers | Add commas; remove decimals and currency symbols where obvious. |
| Empty rows | Never at top of sheet; top row is always a heading or data header. |
| Highlights | Do not highlight cells or rows — highlights break filtering. |
| Groups | Avoid grouped rows; use separate flag/category rows instead. |
| Signs | Revenue positive (+); Opex negative (−). |
| Sum formulas | Use continuous cell ranges or SUMIFS — never disconnected cells. |
| ImportRange | Use sparingly; only bring in what is required. |

## 8. Presentation standards

**For full slide layout rules, load `tern-slide-formatting`.**

### Footnotes

Format: `Notes: 1) [text]. 2) [text].`

| Rule | Detail |
|------|--------|
| Format | "Notes: 1) " — space after closing parenthesis. Full stop at end of each footnote. |
| Text boxes | All footnote text boxes have zero width margin. |
| Ordering | Left to right, top to bottom. Footnote 3 cannot appear before footnote 2. |
| Coverage | Every footnote referenced in the slide body must appear below. |
| Divider | Separate footnotes from main content with a light grey horizontal rule. |

### Standard footnote definitions

| Reference | Definition |
|-----------|-----------|
| EV (distressed) | Total cash commitment for purchase price and working capital. |
| EV (healthy) | Total consideration + earnout in base case scenario. |
| Y1 EBITA | Based on: 1) cost reductions; 2) revenue growth based on average of previous three years; 3) including NED costs; 4) excluding Tern costs. |

### Numbers, dates & punctuation

| Topic | Rule | Example |
|-------|------|---------|
| Numbers in text | Spell out one to ten; use numerals for 11 and above. Exceptions: units, tables, percentages, page numbers. | five companies; 12 deals; 5%; page 7 |
| Negative numbers | Dash, no space. | -£3M |
| Suffixes | Always capitalised, no space. | £10K, £5M, £2B |
| Thousands separator | Numbers of 1,000+ always take a comma, even directly before a K/M/B suffix. | 1,424K not 1424K |
| Ranges | Hyphen, no spaces. | £5-10M, 20-30% |
| Months | First three letters only, no periods. | Jan, Jun, Dec |
| Percentages | Always numeral + % sign. | 5% |
| Sources | Separate with semicolons. | Source: Tern Forecasts; Companies House. |
| Nations | Use periods. | U.K., U.S. |
| Capitalisation | Sentence case throughout. | — |
| Contractions | Spell out where space permits. | "do not" not "don't" |
| Plural abbreviations | Lowercase s, no apostrophe. | CAGRs |
| "na" | Lowercase, no slash. | na |
| Periods | No periods at end of slide headings or table cells. Bullets always end with a full stop. | — |
| Semicolons | Do not use in running prose — break into two sentences. | — |
| EBITA | Always EBITA — never EBITDA. | — |

## 9. Grammar & writing

### Headers

| Style | Use | Rule |
|-------|-----|------|
| H1 | New theme or topic | Short, punchy. Capital letter at start only. Leave one line of space before each H1. |
| H2 | Organising nested topics | Use minimally — only when there are multiple nested sub-topics. |
| H3 | Sub-topic | Short. Capital at start only. |
| All headers | — | Sentence case — not Title Case. No bold within body text. |

### Bullet points — two valid styles

**Bullet glyph hierarchy**: Top-level bullets are always a solid round bullet (●). Sub-bullets (second level and below) are always a hyphen (-), never a round bullet.

**No hanging bullets**: if the last line of a bullet wraps down to a single word, shorten the wording so it doesn't orphan — don't leave it as-is.

**Style 1 — continuation bullets.** Bullets continue the opening sentence. Opening line may end with a colon. Each bullet starts lowercase (unless a proper noun). "And" or "or" before the last bullet. Only the final bullet ends with a full stop.

Example:
> We focus on businesses with:
> · recurring revenue models,
> · strong net retention, and
> · defensible market positions.

**Style 2 — standalone bullets.** Each bullet is a complete standalone sentence, under a heading (no colon). Each starts with a capital letter. Every bullet ends with a full stop.

Example:
> · We focus on founder-led businesses.
> · We back companies with £2-10M ARR.
> · We take a hands-on operational approach.

### Writing principles

| Principle | Rule |
|-----------|------|
| Active voice | Say who does something. "We will consult" not "a consultation will be undertaken". |
| "We" not "I" | Always use "we" or "our" — never "I" or "my". |
| Sentence length | Aim for 15–20 words. Occasional shorter sentences add punch. |
| Plain words | "also" not "moreover"; "before" not "prior to"; "so" not "therefore"; "but" not "however". |
| Verbs over nouns | "We agreed on the deliverables" not "we came to an agreement on the deliverables". |
| No jargon | Cut "leverage" (unless technical), "synergy", "utilise". |
| No bold in body | Bold is for headers only. |
| Fractions | Spell out common fractions. "one third" not "1/3". |
| Ordinals | Spell out first to tenth; numbers for 11th+. | "third quarter"; "11th deal". |
| Articles | Omit "The", "A" etc. to shorten sentences where possible. "Investment rationale" not "The investment rationale". |

## 10. Do's and don'ts

### Do

- Set "Tern" in Semi-bold (600) Tern Orange and "Capital" in Light (300) — no space between them.
- Use DM Sans in Slides and Sheets; Calibri in Excel; Roboto for charts pasted from Sheets into Slides.
- Use square corners on all boxes and tables.
- Write £10K, £5M, £2B — always capitalised, no space.
- Use K and M consistently throughout — 185K charities, 37K institutions (not 37,000).
- Add a comma thousands separator to any number of 1,000+, even before a K/M/B suffix — 1,424K not 1424K.
- Write EBITA — not EBITDA.
- Start footnotes with "Notes: 1) " — space after parenthesis; full stop after each footnote.
- Split sources with semicolons: Source: Tern Forecasts; Companies House.
- End all bullets with a full stop.
- Use "na" for not applicable.
- Set line spacing as Custom: Before = 0, After = 6–12.
- Link all GSheets tables to Named Ranges.

### Don't

- Never add a space between "Tern" and "Capital" or split the wordmark across two lines.
- Never use rounded corners on any box or table.
- Never use orange for body text or large background areas.
- Never write EBITDA — always EBITA.
- Never write £10k, £5m, £2b — lowercase suffixes are incorrect.
- Never mix K and full numbers in the same context (e.g. 185K and 37,000).
- Never split sources with commas.
- Never use "N/A" or "Not Applicable" — write "na".
- Never use direct line spacing — always Custom with Before = 0.
- Never leave a hanging line with only one or two words.
- Never highlight cells or rows in spreadsheets — breaks filtering.
- Never add "Preliminary" to standard data slides — only where data is unclear.
