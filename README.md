# TLL personal skills

Claude skills used for Tern Capital deal and portfolio work. Each folder under `skills/` is one skill: a `SKILL.md` plus any scripts, templates or reference files it uses.

- 17 skills from the `tern-skills` plugin (org marketplace `terncapital/claude_team_skills`), e.g. `assess-deal`, `dd-model`, `spa-review`, `loi-drafter`
- 12 standalone Tern skills, e.g. `employee-contract-review`, `insurance-review`, `mm-questions`, `agenda-builder`

Snapshot taken 2 November 2026. Anthropic's built-in skills (docx, pdf, pptx, xlsx and the examples) are not included.
